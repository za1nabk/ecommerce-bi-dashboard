# E-Commerce Business Intelligence Dashboard

## Overview
An end-to-end business intelligence project analyzing Brazilian
e-commerce transactions using Python, PostgreSQL, SQL, and Power BI.

## Tech Stack
- Python (Pandas, SQLAlchemy)
- PostgreSQL
- SQL
- Power BI

## Data Pipeline
1. Extract e-commerce transaction data from CSV files.
2. Clean and prepare records using Python and Pandas.
3. Load 344,483 records into four PostgreSQL tables.
4. Develop SQL queries and reusable analytical views.
5. Visualize sales performance in Power BI.

## Business Questions
- How does monthly revenue change over time?
- Which product categories generate the most revenue?
- Which Brazilian states contribute the most sales?

## Key Findings
- Beauty & Health generated approximately R$1.23M in product revenue.
- São Paulo generated approximately R$5.07M in product revenue.
- Revenue varied substantially across the analyzed months.

## Dataset
Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.
